# Plan 01: Core Setup, Master Data & Operasional Pasokan-Distribusi

Fokus pada pembangunan fondasi database, autentikasi, master data, pencatatan pasokan petani, hingga penerbitan surat jalan dan hasil timbang PKS.

## Daftar Modul dalam Plan 01
1. `01_setup_dan_database.md` — Migrasi tabel, seeder akun awal, dan konfigurasi layout Blade.
2. `02_modul_master_data.md` — CRUD Petani, PKS Pembeli, dan Harga Beli Harian.
3. `03_modul_pasokan_tbs.md` — Pencatatan timbangan masuk petani & kalkulasi otomatis.
4. `04_modul_distribusi_pks.md` — Surat jalan multi-petani & input nota timbang PKS (rafaksi & selisih berat).
