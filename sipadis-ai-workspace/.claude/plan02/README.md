# Plan 02: Keuangan, Pengupahan, Laporan Laba-Rugi & Testing

Fokus pada penyelesaian modul finansial (pelunasan petani, penerimaan dana PKS, biaya operasional/upah), pelaporan periodik beserta ekspor PDF/Excel, serta pengujian akhir.

## Daftar Modul dalam Plan 02
1. `01_pembayaran_dan_penerimaan.md` — Pelunasan petani (bertahap/lunas) & pencatatan penerimaan dari PKS.
2. `02_biaya_operasional_dan_upah.md` — Pencatatan BBM, upah sopir, dan buruh bongkar muat.
3. `03_laporan_dan_ekspor.md` — Dashboard ringkasan, laporan arus kas, estimasi laba-rugi, dan ekspor PDF/Excel.
4. `04_testing_dan_finalisasi.md` — Rencana pengujian fungsional, validasi perhitungan, dan keamanan akses.
